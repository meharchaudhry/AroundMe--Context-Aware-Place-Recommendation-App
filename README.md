# AroundMe – Context-Aware Place Recommendation App

AroundMe is a student-centric mobile application designed to help university students discover affordable, culturally relevant places and services in a new city. The platform focuses on hyperlocal discovery by combining location context, user preferences, and community-driven insights.

## Problem Statement
Students relocating to a new city often struggle to find trustworthy, budget-friendly, and relevant places that match their daily routines and preferences. Existing map-based tools provide generic listings but do not account for student-specific constraints such as affordability, cultural relevance, or common travel routes.

## Solution Overview
AroundMe addresses this gap by delivering personalized, hyperlocal recommendations tailored to student needs. The app enables users to explore cafés, eateries, services, and cultural spaces based on proximity, budget, and purpose, making city navigation more intuitive and accessible.

## Key Features
- **Context-Aware Recommendations** based on user location, daily routes, and affordability constraints  
- **Hyperlocal Discovery** focusing on student-friendly neighborhoods and hidden local spots  
- **Community-Driven Insights** using user reviews and interactions to improve recommendation relevance  
- **Conversational AI Chatbot** allowing users to ask natural-language questions and receive quick, trusted recommendations  
- **Gamified Engagement** through badges, contribution points, and exploration challenges

## Approach
- Conducted community and user research using student discussions, social platforms, and public sources to identify key discovery patterns and constraints.
- Designed a hybrid recommendation approach combining location context, user preferences, and interaction signals.
- Integrated an AI-powered chatbot interface to support intuitive, natural-language-based discovery.

## Tech Stack
- Mobile Application Development
- Location-Based Services
- Natural Language Processing (NLP)
- Recommendation Systems
- Python

## Impact
- Improved ease of city navigation for students new to Pune.
- Reduced search friction for affordable and relevant places.
- Demonstrated a scalable framework for student-centric urban discovery.
